# 接口依据 v1

核对日期：2026-10-22。以下均为官方文档。预设保留完整接口地址和可编辑模型ID，账号权限及服务商变更仍以平台实际响应为准。

| 服务 | 对话地址 | 预设模型 | 依据 |
| --- | --- | --- | --- |
| DeepSeek | https://api.deepseek.com/chat/completions | deepseek-flash | [首次调用](https://api-docs.deepseek.com/guides/search_fetch) |
| Kimi | https://api.moonshot.cn/v1/chat/completions | kimi-k3 | [快速开始](https://platform.kimi.com/docs/get-api-key) |
| GLM | https://open.bigmodel.cn/api/paas/v4/chat/completions | glm-5.3 | [GLM-5.3](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3) |
| 自定义 | 用户指定，HTTPS且以/chat/completions结尾 | 用户指定 | Chat Completions SSE或JSON兼容服务 |

DeepSeek 和 GLM 预设使用 thinking enabled、reasoning_effort low；Kimi K3 使用 reasoning_effort low、max_completion_tokens。仅对匹配预设服务商和模型族应用对应参数，不向自定义模型附加这些专用字段。推理过程不展示、不落盘；对话存储只保留普通正文。

搜索统一采用 [GLM Web Search API](https://docs.bigmodel.cn/api-reference/工具-api/网络搜索)，POST `https://open.bigmodel.cn/api/paas/v4/web_search`，请求字段 search_query、search_engine=search_std、count=8、content_size=high；读取 search_result 中 title、content、link、media、publish_date。限制摘要长度，过滤非HTTP(S)来源及重复链接。搜索概览见 [官方联网搜索说明](https://docs.bigmodel.cn/cn/guide/tools/web-search)。

三家模型接口按官方格式做本地协议检查，没有真实Key实网调用。搜索能力也只完成协议和模拟错误验证。自定义代理不复用到官方搜索，避免向另一主机发送代理凭证。


## 语音输入依据（2026-10-24）

[Android SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)用于系统语音服务、按需RECORD_AUDIO权限和RecognitionListener回调。Android 11及以上声明RecognitionService可见性；Android 12及以上检查本地识别服务可用性。服务只用于用户主动发起的一段输入，不持续监听；结束时销毁识别器。

[Android RecognizerIntent](https://developer.android.com/reference/android/speech/RecognizerIntent)用于系统语音输入窗口降级，捕获不可用与权限异常。系统服务可能联网，本应用只接收识别文字。语音结果不自动调用模型或记账。
