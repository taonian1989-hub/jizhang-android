# 记账 产品定义 v1

面向一位不想维护复杂账本、又希望掌握收支的个人用户。免登录，人民币优先，离线可用，模型服务可自由配置。

主任务链为描述花费、检查卡片、确认入账、看懂收支、调整预算。AI 是整理与解释层，金额与资产余额由确定性的本机程序计算。AI 没有直接改账或支付能力。

五个视图分别是概览、账单、助手、洞察和资产。概览优先给出月支出、收入、结余和一句话入口；设置收纳模型、搜索、备份和管理功能。小屏使用底部导航，大屏使用侧边导航。浅色以暖白和深绿为主，深色以暖黑绿和浅绿为主；不依赖颜色区分收支。

首版功能参照钱迹的账本、账户和预算体系，以及 YNAB 对预算、目标与交易管理的分工，并结合用户免登录、本机存储、独立模型接入的要求定义。没有复制这两款产品的页面或素材。

账户跨账本共享余额，收支和预算按账本统计。退款记录为独立正金额，影响为冲减支出；转账是一个同时影响两个账户的交易。储蓄目标是手动进度，避免用户把一次真实转账与一次目标进度重复计算。周期计划不是已付款事实，需要到期后确认。

数据只读保护用于快照损坏或无法解密时。用户可以导出原始诊断副本，或主动导入已保存的有效备份；应用不会默默创建并覆盖空账本。

后续可根据实际使用反馈扩展截图识别、支付平台CSV适配、系统提醒、报销状态、年度汇总与多币种；这些不在本版已完成清单内。
