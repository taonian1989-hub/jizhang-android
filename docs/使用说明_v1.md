# 记账 0.1.2 使用说明

## 安装与开始

支持 Android 8.0 及以上，建议更新 Android System WebView。将 `记账_0.1.2_预览版.apk` 传到手机，允许当前文件来源安装后打开。没有登录环节。

先到「资产」点击现金、微信、银行卡，设置开始记账前的余额。可以添加自己的账户；信用卡账户期初欠款请填负数。余额只依据用户输入与账单计算，不连接银行。

## 记一笔

在概览输入 `早餐18，地铁3`，助手会在本机整理成两张待确认卡片。卡片展示金额、类别、日期和账户；点击检查可以修改，点击确认才入账。默认使用第一个账户，可在卡片里切换。简单离线语句要求每句只有一个阿拉伯数字金额，不能把“1万”当成“1元”。

复杂描述可在配置模型后使用助手，或从首页输入自动尝试模型。AI 识别只是候选结果，确认前请看清金额和日期。也可点「记一笔」手工输入。首页和助手输入框均有麦克风按钮，可用系统服务将语音转成文字。

「支出」减少余额；「收入」增加余额；「退款」增加余额并冲减支出；「转账」同时减少转出账户、增加转入账户，不计入收支。信用卡还款应选银行账户转入信用卡账户。

## 语音输入

首页“一句话记账”和助手输入框右侧都提供麦克风按钮。首次使用时，允许系统请求的麦克风权限，然后说出花费或问题。可点“说完了”结束，或点“取消”保留原文字。识别结果先插入光标位置或替换选中的文字，不自动发送、不自动入账。

文字回填后，首页点箭头识别候选账单，助手点发送再提问。识别结果可手工修改；若系统输出中文数字且离线规则不能识别，可改为阿拉伯数字，或交给已配置的AI整理。

语音使用手机系统服务，本地服务可用时优先使用；系统服务及其中文语音包、联网要求取决于机型。应用不保存原始录音。未安装或启用系统服务时会明确提示，可使用输入法麦克风；拒绝权限时可点提示中的设置入口授权。取消后、离开页面后或进入后台后，旧结果不会填入另一个输入框。

## 四种记账类型

| 类型 | 账户字段 | 分类字段 | 金额含义 |
| --- | --- | --- | --- |
| 支出 | 付款账户 | 支出分类 | 减少账户余额 |
| 收入 | 收款账户 | 收入分类，工资、奖金及自定义分类 | 增加账户余额 |
| 转账 | 转出账户、不同的转入账户 | 不显示、不填写、不保存 | 只移动账户间资金，不计入收支 |
| 退款 | 退款到账账户 | 冲减的支出分类，与原消费一致 | 增加余额、冲减对应支出 |

日期、账本、可选备注和标签适用于四种类型；备注与标签提示随类型变化。切换时保留已输入金额、日期、备注，并记住各类型已选分类。只有一个账户时不能保存转账，需先到资产页添加账户。旧账单如使用了与当前类型不同的分类，编辑时标记为“原分类”保留，避免默默改写。

## 管理与看懂收支

- 账单页切换月份、类型，搜索备注、分类、标签、账户名或金额，点击记录编辑。删除会二次确认。
- 预算计划分别设置所选月份的总预算和分类预算。预算不自动复制到下个月，0或留空为不设。
- 洞察展示分类净支出、六个月趋势、月结余和自然日日均支出。转账不参与消费统计，退款按退款发生月份冲减。
- 账本可以新建和重命名，收支与预算分开统计；账户余额仍汇总全部账本。
- 周期账单支持按月或按年。到期后会在概览出现，只有点击确认已支付后才入账、推进下一期。没有后台通知。
- 储蓄目标是单独的累计进度，更新进度不产生收支或转账。

## 连接 AI

设置 → 模型连接，选择 DeepSeek、Kimi、GLM 或自定义服务。粘贴自己在服务商开放平台创建的 API Key，检查完整 HTTPS 对话地址、模型ID、输出上限，保存并测试连接。API Key 不是聊天产品的登录密码，也不保证聊天会员包含 API 额度。不要把 Key 发到对话里。

预设 ID 可手动修改，服务商的账号权限和额度以平台为准。改变 API 地址时需重新输入 Key。模型切换到另一服务商后清空当前对话，避免把之前的上下文带给另一家服务商。

普通提问可直接发送。需要分析个人花销时，主动勾选「附带当前账本摘要」；发送所选月份的统计、分类和预算，不发送逐笔账单备注。账户名和分类本身会提供给模型，以便识别账单时选择正确的本地 ID。

升级后旧 GLM 搜索设置自动改为 DeepSeek；原有 GLM 模型配置保留供对话使用。需要公开资料时先配置 DeepSeek 官方 Key，再勾选「联网搜索」。搜索使用 DeepSeek 独立 Search API，可搭配 Kimi 或 GLM 生成回答；已保存的 DeepSeek 官方 Key 可直接复用，无需 GLM 搜索 Key。只发送本次输入开头最多128字作为搜索词；请勿混入个人隐私。点击来源卡片可在系统浏览器核查。失败会显示错误，应用不自动重试付费请求。

停止生成、响应截断、格式校验失败时不提取待入账卡片。识别草稿不跨重启保存，请确认入账或自行取消。

## 备份和导入

设置 → 数据备份与导入 → 导出完整 JSON，选择手机文件位置。备份包含账本、账户、账单、预算、周期计划和目标，不含模型Key和聊天。备份为明文，请保管。

导入 JSON 时先显示账本、账户和笔数；确认后替换本机账本。建议先导出现有数据。模型密钥保留，不从备份恢复。

CSV 适合用 Excel 查看；导入只支持本应用列格式：日期、类型、金额、分类、账户、转入账户、账本、备注、标签。转账的分类可留空。类型使用 expense/income/transfer/refund，金额单位元。须先建立对应名称的分类、账户和账本。导入前预览待追加和重复数量，再确认。重复判断包含日期、类型、金额、分类、两端账户、账本、备注和标签。

## 常见情况

模型配置保存后还需测试连接；HTTP401/403通常与密钥或权限有关，404可能是模型或地址不匹配，429为限流或额度不足。搜索还需要 DeepSeek 搜索权限与额度，模型可以调用不代表搜索一定可用。

账本读取失败会进入只读保护，不覆盖原始文件。请保留应用数据，尝试重启，或导出诊断副本；有有效 JSON 备份时可明确选择恢复。诊断文件不是可直接恢复的明文账本。

卸载、清除数据或更换手机会丢失本机数据，务必先导出再恢复。不要以不同签名的APK强行覆盖安装。此版未连接真机、实际麦克风或使用真实Key验证，建议先用少量非敏感记录试用并确认备份流程。
